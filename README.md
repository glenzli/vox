# Vox

脚本驱动的配音制作。Script-led voice production.

Vox is a public planning repository for a dedicated script-to-voice production application:
narration, multi-speaker dialogue and listening materials.

**Status: planning only. There is no standalone Vox application or release yet.**
Existing script authoring and speech synthesis remain in
[Shape](https://github.com/glenzli/shape) and continue unchanged.

The proposed product centers on scripts, roles, voice choices, pauses, repeated passages,
sound cues, audition and production revisions. General one-shot text-to-speech can remain a
Shape processing capability; specialist waveform editing and mixing belong in
[Echo](https://github.com/glenzli/echo).

The initial plan is to reuse Shape's production-script parser, synthesis assembly and validation
when a complete independent editing and persistence boundary is ready. No source has been
migrated into this repository.

See [the roadmap](ROADMAP.md).
